01[ individual → coach → team ]

Threelevels

Levels A team is never one shared folder: every athlete opens their own folder, built from the same template in every context.

  • IndividualPersonal dashboard → your own athlete folder/ one profile
  • CoachCoach dashboard + My Athletes/ one folder each
  • TeamOrganization → squads → rosters/ individual folders

The same athlete can appear in Individual, a coach’s list and a squad roster — always one folder, one set of data. Team sessions link many athletes while each athlete’s execution stays separate. Open the Hub.
