01[ unified athlete database — individual → coach → team ]

One athlete,one folder

Every athlete has one profile and one folder. A coach opens many folders, a team opens a roster — but nothing is ever copied: Individual, Coach and Team read the same athlete database.

    Learn

    Books, manuals and guides from the APS Store — knowledge written to be used on the training ground.

03[ performance hub — individual → coach → team ]

  • IndividualOne athlete profile/ your own folder
  • CoachMany athletes/ one folder each
  • TeamOrganization → squads → athletes/ individual folders
